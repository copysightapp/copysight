What CopySight accesses

Nothing to sign in to

CopySight has no backend. It only asks macOS for Screen Recording permission so it can read the pixels you select.

Only the menu bar

The app has no Dock window. Settings cover the shortcut, OCR language, line breaks, sound, login launch, and Spanish or English interface.

Source included

App, CLI, packaging scripts, tests, and this website are published under the MIT license.

Apple Silicon and Intel

The signed release is universal and runs on macOS 14 or later.

Questions before installing

Does CopySight upload screenshots?

No. Screen capture and OCR run locally with ScreenCaptureKit and Vision. Captured images are not saved.

Why is Screen Recording permission required?

macOS protects screen pixels. CopySight needs that system permission only to capture the region you draw.

Which languages work?

Automatic detection is the default. English and Spanish can also be selected explicitly for more predictable correction.

Can I use it from scripts?

Yes. The copysight CLI writes recognized text to stdout and errors to stderr.
