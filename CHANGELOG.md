# Changelog

## 1.1.0 — 2026-08-03

- El atajo predeterminado pasa a `⌃⌘2` para abrir el selector de región.
- Ajuste opcional nativo para abrir CopySight al iniciar sesión.
- Interfaz completa en español e inglés según el idioma de macOS.
- La ayuda del selector aparece en la esquina superior izquierda y no tapa el contenido.
- Preparación de la distribución sandbox para Mac App Store.
- Web más directa y enlace de instalación desde App Store.

## 1.0.0 — 2026-08-03

- Captura OCR de una región en cualquier pantalla mediante ScreenCaptureKit.
- Reconocimiento local preciso con Vision, detección de idioma y corrección.
- Copia automática al portapapeles, repetición de la selección anterior y atajo configurable.
- Aplicación AppKit de barra de menús para Apple Silicon e Intel.
- Empaquetado Developer ID notarizado y web pública de instalación.
