# First run

1. Install CopySight from the Mac App Store or move `CopySight.app` from the direct-download DMG to **Applications**.
2. Open CopySight. Its viewfinder icon appears in the menu bar; the app does not add a Dock icon.
3. Press `⌃⌘2` or choose **Capture Text**.
4. Allow **Screen Recording** for CopySight when macOS asks. Quit and reopen the app if the system requests it.
5. Drag over a visible sentence, then paste with `⌘V` to verify the result.

CopySight does not require Accessibility permission, a network connection, or an account. Screen Recording permission is required because macOS otherwise prevents the app from reading pixels in the selected region.
