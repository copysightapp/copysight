# Primer uso de CopySight

1. Descomprime `dist/CopySight-1.1.0-macos.zip` y mueve `CopySight.app` a **Aplicaciones**.
2. Abre CopySight. Su icono aparecerá en la barra de menús; no crea un icono en el Dock.
3. Pulsa `⌃⌘2` o elige **Capture Text**.
4. La primera vez, permite **Grabación de pantalla** para CopySight en Ajustes del Sistema. Si macOS lo solicita, cierra y vuelve a abrir la app.
5. Arrastra sobre una frase visible y pégala con `⌘V` para comprobar el resultado.

CopySight no necesita Accesibilidad, conexión de red ni una cuenta. El permiso de Grabación de pantalla es imprescindible para que macOS permita leer los píxeles de la región seleccionada.
